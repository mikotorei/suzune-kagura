# 鈴音神楽 ギルドサイト

マビノギモバイル トゥガルドアイルサーバーのギルド「鈴音神楽」の非公式ファンサイトです。

公開URL：https://mikotorei.github.io/suzune-kagura/

`main` ブランチが更新されると、GitHub Actions が自動でサイトを作り直して公開します（数分かかります）。

---

## 記事を書く

運用方針：ギルドの顔＋活動記録。出来事があったときだけ、画像中心＋短い文で載せる（攻略情報はDiscordの豆知識に置き、サイトには載せない）。

### テンプレート
`src/content/articles/_template.md` をコピーして使います。

- ファイル名：出来事の日＋英字の名前（例：`2026-11-18-ship-complete.md`）。頭に `_` は付けない
- `eventDate`：出来事があった日。記事には「2026年11月18日のできごと」と表示され、一覧もこの日付の順に並ぶ
- `date`：公開する日。後から書いたときは、記事に「11月25日公開」も小さく出る。その日に書くなら `eventDate` と同じでOK
- `category`：ギルド日記／イベント／お知らせ
- `draft: true` のあいだは公開されない。書き溜めておいて、出すときに `false` にする
- 画像は `public/images/articles/ファイル名と同じフォルダ/` に置く。画像の直後の段落は、画像の説明として小さめに表示される

### 記事を書くときの決まり
- 公式サイトの文章や画像をそのまま貼らない
- ゲームのスクショや公式の文章をAIに読み込ませて記事の中身を作らない（ネクソンの著作物利用ガイドライン）
- メンバーのキャラ名やスクショは本人の了承をもらってから
- コラボキャラクターの画像は使わない

カテゴリーを増やしたいときは `src/consts.ts` の `CATEGORIES` と `CATEGORY_SLUGS` に足します。

## 合言葉を設定する（PCで）

```bash
npm install        # 初回だけ
npm run invite
```

Discordの招待リンクと合言葉を聞かれるので入力します。合言葉でリンクを暗号化して `src/data/invite.json` に保存します（合言葉もリンクも平文では残りません）。

保存したらGitHubに反映し、**ゲーム内のギルド告知の合言葉も同じものに変えて**ください。

- 合言葉は、ひらがな／カタカナ、全角／半角、前後の空白の違いを区別しません
- 合言葉が外に漏れたら、Discordで招待リンクを作り直して `npm run invite` をやり直すだけで切り替わります
- 招待リンクは「有効期限：無期限」で作っておくと、切れて使えなくなることがありません

## 手元で表示を確認する（PCで）

```bash
npm install
npm run dev
```

表示された `http://localhost:4321/suzune-kagura/` をブラウザで開きます。

## ファイルの場所

| 変えたいもの | ファイル |
| --- | --- |
| トップページ | `src/pages/index.astro` |
| ギルドについて（約束・お願い） | `src/pages/about.astro` |
| 参加方法 | `src/pages/join.astro` |
| 配色・文字 | `src/styles/global.css` |
| ヘッダー・フッター | `src/layouts/Base.astro` |
| サーバー名などの基本情報 | `src/consts.ts` |
| ギルドのアイコン | `public/images/emblem.webp`（ほか `favicon.png` など） |
